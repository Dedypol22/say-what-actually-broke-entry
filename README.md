One line of software error copy that tells the user the brutal truth about what went wrong and makes them laugh: the save failed because the disk is full of the user's own drafts named final_FINAL_v2, and the program was too polite to delete any of them. It names the real failure, lands on a single read, and is honest enough that a team could actually ship it in a dialog.
